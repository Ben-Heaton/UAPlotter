# UAPlotter

Developing a full-stack web application (Django, Leaflet.js, SQLite) that will visualise real-world UAP sighting data from NUFORC on an interactive map, allowing users to explore reports geographically.

## Tech stack

- **Backend:** Django
- **Frontend:** Leaflet.js
- **Database:** SQLite

## Data source

Sighting data sourced from [NUFORC](https://nuforc.org).
